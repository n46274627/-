# מי מסתתר מאחורי השם? — אב־טיפוס

## דרישות
- Node.js 18 ומעלה
- חיבור לאינטרנט רק אם מפרסמים את השרת ברשת

## הפעלה במחשב
1. חלצו את קובץ ה-ZIP.
2. פתחו Terminal / PowerShell בתוך התיקייה.
3. הריצו:
   ```bash
   npm install
   npm start
   ```
4. פתחו בדפדפן: http://localhost:3000

## משחק עם חברים
כדי שחברים ייכנסו ממחשבים וטלפונים שונים, צריך לפרסם את הפרויקט בשירות אירוח שתומך ב-Node.js וב-WebSockets, למשל Render או Railway.
אחרי הפרסום, שולחים לכולם את כתובת האתר. שחקן אחד יוצר חדר ושולח את קוד החדר לאחרים.

## מה עובד בגרסה הזאת?
- יצירת חדר עם קוד בן 5 תווים
- הצטרפות עד 20 שחקנים
- שם אמיתי ושם בדוי לכל שחקן
- השמות האמיתיים לא נשלחים לממשק השחקנים בזמן המשחק
- צ'אט קבוצתי
- ניחוש זהות וניקוד
- מנהל חדר יכול לסיים ולחשוף את הזהויות

## מגבלות שחשוב להכיר
- זהו אב־טיפוס: החדרים נשמרים בזיכרון, ולכן נמחקים כשהשרת נכבה.
- רענון דף או ניתוק מנתקים את השחקן; בגרסה הבאה נוסיף חזרה לחדר.
- אין אימות שהשם שהוקלד הוא באמת של אותו אדם. משחקים רק עם אנשים שמסכימים להשתתף.
- אין להשתמש בסיסמאות, כתובות, פרטים אישיים רגישים או מידע שמישהו לא הסכים לחשוף.
- זה לא מוצר מאובטח לפרסום מסחרי; לפני פרסום רחב צריך להוסיף אימות, הגבלת קצב, שמירת נתונים מאובטחת והגנות נוספות.

## איך הניקוד עובד?
- ניחוש נכון: 10 נקודות.
- ניחוש שגוי: מינוס 2 נקודות (לא יורדים מתחת לאפס).
- כל שחקן יכול לנחש כל משתתף פעם אחת.
